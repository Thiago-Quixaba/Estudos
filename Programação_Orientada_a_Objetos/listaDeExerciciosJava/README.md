# ☕ Lista de Exercícios Java

Repositório dedicado à resolução de uma lista de exercícios da disciplina de **Programação Orientada a Objetos (POO)**, utilizando a linguagem Java.

O projeto reúne 17 exercícios desenvolvidos com o objetivo de praticar conceitos fundamentais de programação, lógica computacional e manipulação de dados.

## 📚 Exercícios

| Questão | Descrição |
|:---:|---|
| 01 | Verificação e classificação de triângulos. |
| 02 | Construção de um quadrado vazio utilizando asteriscos. |
| 03 | Conversão de números binários para decimais. |
| 04 | Identificação de números perfeitos. |
| 05 | Calculadora utilizando a estrutura `switch`. |
| 06 | Extração do nome de um arquivo a partir de seu caminho. |
| 07 | Verificação de permutação entre dois números. |
| 08 | Cálculo de moda, mediana e média de um vetor. |
| 09 | Ordenação de um vetor em ordem crescente. |
| 10 | Verificação de palíndromos. |
| 11 | Soma dos elementos da diagonal secundária de uma matriz. |
| 12 | Cálculo de expressões matemáticas. |
| 13 | Identificação de números que satisfazem determinada propriedade matemática. |
| 14 | Cálculo do Máximo Divisor Comum (MDC). |
| 15 | Análise de um vetor: distância entre posições, ordenação e comparação com X. |
| 16 | Verificação de progressão aritmética (PA). |
| 17 | Multiplicação de matrizes. |

Algumas questões possuem classes auxiliares para separar responsabilidades e organizar melhor a implementação.

## ⚙️ Tecnologias utilizadas

- **Java:** Linguagem de programação utilizada no desenvolvimento.
- **JDK:** Kit de desenvolvimento necessário para compilar e executar os programas.

**Observação:** Cada questão possui sua própria classe `Main`, permitindo que os exercícios sejam compilados e executados individualmente.

## 🎯 Objetivo

Praticar e desenvolver habilidades de programação em Java por meio da resolução de problemas envolvendo estruturas condicionais, estruturas de repetição, vetores, matrizes, métodos, classes e algoritmos matemáticos.
